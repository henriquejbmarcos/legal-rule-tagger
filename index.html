Legal Rule Tagger

How to use this tool

Paste your legal text into the box below. Then select a part of it with the mouse and press one of the three buttons at the top left to tag it.

Try it first on the example sentence that is already in the box:

A contract is formed if there is an offer and an acceptance, provided that the offer is made verbally or in writing.

  1. Select “A contract is formed” and press Consequence. This is what the rule brings about.
  2. Select “an offer”, then “an acceptance”, pressing Cumulative Condition each time. Both are needed.
  3. Select “verbally”, then “in writing”, pressing Alternative Condition each time. Either one is enough.

The panels below fill in as you tag: the consequence, the cumulative conditions and the alternative conditions are listed separately, and each has a box for your own notes. At the bottom, every tagged part appears as a node in the mind map, which you can drag with the mouse.

Undo removes the last tag. Clear empties the box and the notes. Export saves your work as a file and Import opens it again later. Print produces a clean copy, or a PDF if you choose “Save as PDF”.
